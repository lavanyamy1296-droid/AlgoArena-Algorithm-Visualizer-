# AlgoArena — Algorithm Playground

AlgoArena is a browser-based interactive learning lab for core computer science concepts.

## Features
- **Sorting Lab:** Bubble Sort, Selection Sort and Insertion Sort visualizations with adjustable array size and speed, comparisons and swaps/shifts counters.
- **Search Lab:** Linear Search and Binary Search with animated step-by-step checks, result index and complexity.
- **Data Structures:** Interactive Stack (LIFO) and Queue (FIFO) with push, pop, enqueue and dequeue operations.

## Run locally
No installation, package manager, backend, API key or Python environment is required.

1. Extract the ZIP.
2. Open the `AlgoArena-Algorithm-Visualizer` folder in VS Code.
3. Double-click `index.html`, or right-click it and choose **Open with Live Server** if you already use that VS Code extension.
4. Use the tabs to explore each playground.

You can also open `index.html` directly in Chrome, Edge or Firefox.

## Technology
- HTML5
- CSS3
- Vanilla JavaScript

All visualizations run locally in the browser. No data is uploaded.

## Learning notes
- Bubble, Selection and Insertion Sort have O(n²) average/worst-case time complexity.
- Linear Search has O(n) time complexity.
- Binary Search has O(log n) time complexity and requires sorted input.
- A Stack follows Last In, First Out (LIFO).
- A Queue follows First In, First Out (FIFO).
